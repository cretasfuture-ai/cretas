# 数字员工形象规格（给 Codex）

F 线原型里形象只留占位（首字 + 状态点，组件 `accounts/unified-v1/src/crew/CrewAvatar.vue`）。正式的形象、名字、头像由 Codex 出，按本规格交付后替换占位，不改页面结构。

## 1. 要几位
五位：数字文员、数字仓管、数字计划员、数字质检员、数字成本会计。名字可以另起（对外品牌名），原型里的「数字 X」是岗位名，形象上不要写字。

## 2. 尺寸（每位每种状态都要）
| 尺寸 | 用在哪 | 说明 |
|---|---|---|
| 24×24 | 主动汇报列表、入职上岗条件卡、表格行 | 只看得出轮廓和颜色，细节可省 |
| 40×40 | 班组首页卡片、工作台对话区头部、手机端顶栏 | 主力尺寸 |
| 64×64 | 工作台空状态、入职完成页 | |
| 96×96 | 路演大屏、班组介绍 | 可以有更多细节 |

- 交付 SVG（首选）或 2 倍 PNG（48 / 80 / 128 / 192 像素）；透明背景；圆形安全区（内容在内切圆里，页面会裁成圆）。
- 浅色、深色两种页面背景都要看得清（深色模式页面背景约 #10161f）。
- 不用渐变光晕、不用会动的眼睛之类装饰（一线手机端要省电、可读）。

## 3. 四种状态
状态由页面根据数据决定，形象本身要能配合表达。原型里用右下角状态点（占形象直径约 30%，带 2px 白边），正式形象可保留状态点，也可以改成姿态变化，但**四种状态在 24px 下也必须分得清**，且不能只靠颜色（色弱用户）：

| 状态 | 页面里什么时候出现 | 原型状态点 | 建议 |
|---|---|---|---|
| 空闲 | 没有等确认、没有问题、没在办 | 灰 #a9b8c7 | 中性表情 / 静止 |
| 办理中 | 用户确认后正在调接口；对话里正在算 | 蓝（信息色），1.5 秒呼吸闪烁；系统开了「减少动态效果」时不闪 | 低头做事 / 手里有东西 |
| 等你确认 | 有预览在「等我确认」里没人确认 | 黄（警示色） | 举手 / 递东西的姿态 |
| 发现问题 | 主动汇报里有未处理的「问题」 | 红（危险色） | 感叹号 / 指向某处，不要显得惊恐 |

- 颜色用设计系统变量：信息 `--cs-info`、警示 `--cs-warning`、危险 `--cs-danger`、中性 `#a9b8c7`，不要另造颜色。
- 每种状态的无障碍文字由页面提供（`aria-label`：「数字计划员 · 等你确认」），图片本身不带文字。

## 4. 风格边界
- 是「班组里的同事」，不是吉祥物或机器人玩偶；五位要像一套（同一画风、同一比例），靠服装 / 道具区分岗位：文员（单据夹）、仓管（货架或叉车元素）、计划员（排程板）、质检员（放大镜或检验牌）、成本会计（计算器或账本）。
- 不出现真实人物肖像、真实企业标志、食品品牌。
- 一线手机端顶栏只出现一位（按登录人岗位），不要设计成五人合影作为入口。

## 5. 交付与替换
- 文件放 `accounts/unified-v1/src/crew/avatars/<id>-<state>.svg`，id = clerk / keeper / planner / inspector / accountant，state = idle / working / waiting / alert（共 20 个；若用状态点方案，只要 5 个底图 + 页面画点）。
- 替换方式：`CrewAvatar.vue` 改成按 `name→id`、`state` 取图，保留现有 `data-state`、`aria-label`、尺寸参数；页面其余部分不动。

## 6. 接入状态（2026-11-13）
正式形象已接：`src/crew/avatars/<id>.png`，从 Codex 黏土五人版原图裁出的胸像（192×192），状态仍用状态点。四种状态的姿态没有接：Codex 的动作是待机 / 工作 / 等待确认 / 完成，没有「发现问题」，也没有静态分状态图。详见 `impl-F.md` 第 12 节。
