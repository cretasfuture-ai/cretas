## 一 · 老板看到的（prod 原文）

问：**「最近30天水煮牛肉丝卖得怎么样」**（菜单里只有「水煮牛肉」）

```
具体菜品我这次跑出来了，但里面有几句话没达到我们「不把推测说成结论」的要求，
所以我没发给你 —— 我不会拿别的数据凑，也不给你一个我不敢担保的因果结论。
你可以把问题问得更小一点（限定到某家店、某道菜或某个时间段），
那条路我能给你确定的数。
```

对照 **「麻婆豆腐」**（完全不像任何真菜）拿到的是**正确**的 150 字目录反馈：

```
**菜单里没查到「麻婆豆腐」这道菜**，所以没法单独给它的销量或毛利 ——
也不会拿别的菜的榜单顶替。
· 是刚上架的新菜吗？…
· 还是我认错了字？在售的菜有：凉拌木耳、娃娃菜、…（共 10 道），报个名字就行。
```

## 二 · 缺陷说准（⛔ 我登记的那句是错的）

我原来登记的是「近似菜名**够不着目录反馈**」。实测把它订正成三条：

1. ⛔ **不是**静默顶替 —— 它**没有**把「水煮牛肉」的数说成「水煮牛肉丝」的。
   **这点是好的**，而我原本预测它会（本轮第二次预测这条路失败）。
2. 🔴 老板拿到的是一句**讲产品自己内部质量流程**的话，而真正的原因
   （菜单里没这道菜）产品**手上就有**。
3. 🔴 它给的出路是「把问题问得更小一点，**限定到某道菜**」——
   老板**已经**限定到某道菜了。⇒ **一条他做不到的指引**
   （与 2026-08-18 建厂那次「客户读到一句他做不到的指引」同形）。

⇒ 交付定义⑤（说清缺什么 / 怎么拿到 / 他自己要干什么）**三件事一件都没给**。

⚠️ 「具体菜品我这次跑出来了」这句话本身是证据：**执行链真的拿另一道菜的数据
算了一遍**，接地闸只是最后一道保险，而它拦下的理由还是别的。
⇒ **修法必须在更前面。**

## 三 · 成因

`_catalogue_says_not_a_dish` 有**两个方向**的子串放行：

```python
if candidate in name:                       # 老板说了半个菜名（「水煮」）  合理
    return False
if len(name) >= 2 and name in candidate:    # 老板说的比菜名长（「水煮牛肉丝」）← 就是它
    return False
```

第二条把「另一道菜 / 打错字」也放行了 ⇒ 判定侧认为「它在菜单里」⇒
目录反馈那条路走不到 ⇒ 走执行 ⇒ 接地闸兜底。

## 五 · 修法 —— 另起一个**窄**判据，⛔ 不动共用的那个

```python
def _catalogue_says_a_longer_name(candidate) -> bool:
    """老板打的名字比菜单里的那道长 —— 多打了字，或者那是另一道菜。"""
```

接法是 `_catalogue_says_not_a_dish(c) or _catalogue_says_a_longer_name(c)`，
**两处消费点用同一个组合**（AST 断言钉着；漂了的表现是「判定说没有、措辞说有」）。

### 判据是量出来的（`_dish_longer_than_menu`，prod）

| 判据 | 误伤(必须 0) | 该拒的拒了 | 阳性对照 |
|---|---|---|---|
| P0 现状 | 0 | **1/4** | OK |
| P1 只留「说了半个菜名」 | **10** | 4/4 | OK |
| P2 P1 + 剥口语后缀 | 0 | 4/4 | OK |
| P3 切出菜名、只判尾巴 | 0 | 3/4 | （单独看不该拒麻婆豆腐）|
| **P4 = P0 ∨ P3（上的就是它）** | **0** | **4/4** | **OK** |

⚠️ P1 的 10 条误伤**不是构造出来的假风险**：抽取器实测会把口语后缀带进槽位
（`extract_dish_candidate("凉拌木耳这道菜卖得怎么样") == "凉拌木耳这道菜"`）。

### ⛔ 为什么不选 P2（它也满足三条）

P2 要一张**新的口语后缀词表**，而词表棘轮 `MAX_UNREGISTERED = 88`
**当前正好 88（零余量）**，`test_the_limit_is_not_slack` 容差 3 不许调高。
⇒ P3 复用**已登记的** `_DISH_GENERIC_TOKENS`，**零新增词表**（棘轮改动后仍绿）。

⚠️ 只对**已经与菜名切开的尾巴**用 —— 直接对整个候选贪心剥尾会把
「干锅花**菜**」剥成「干锅花」（「菜」就在那张表里）。

### 🔴 判据订正：形态 A 出现在**我自己的仪器**上

第一版给 P3 配的阳性对照是「麻婆豆腐必须被拒」，实测 `P3=False`，
我差点读成「P3 不合格」。而 P3 是**故意窄**的，麻婆豆腐归**现有**判据管。

▎我想知道的 X = 「接上去之后覆盖全不全」；我实际量的 Y = 「P3 单独覆盖全不全」。

⇒ 加了 P4 = P0 ∨ P3 让仪器自己说，⛔ 没手算。
