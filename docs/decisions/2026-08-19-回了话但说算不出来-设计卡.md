## 1. 真正的缺陷：Q16 的**出路**是假的（Q18 的是真的）

### 修前原文（prod 逐字，3/3 轮 `fp=46a57ca6`、`tier=llm`，⛔ 不是缓存回放）

> **近 30 天的食材成本率算不出来。**
> 营收这一侧有：¥20,782,887.14（57,768 单）。

### 三条实测，逐条打掉后两件事

**(a) 「盘点数据进了系统，这个数就能算」——已经被现状证伪。**

MOCK_REST 早就盘过了：`fact_restaurant_stocktaking` **1,970 行、8 个盘点日全部
`COMPLETED`**（近 30 天窗口内 4 个：07-27 / 08-03 / 08-10 / 08-17 ——

而 `fact_cost_line` **仍然 0 行**。
▎老板照这句话去做，**已经做完了，什么也没拿到**。

**(b) 结构上也不可能。** `fact_restaurant_stocktaking` 的 16 列里没有**库存金额**：
只有 `system_qty / actual_qty / difference_qty / difference_cost`（盘盈亏差额）。
公式要的「开始那天的库存金额」「结束那天的库存金额」**整个 schema 里都没有地方记**。

**(c) 「进货金额系统里已经有了」也是假的。**
`agg_restaurant_daily_ops` 里 `purchase_amount` / `purchase_cost` / `inbound_amount`
**各 0 行**；该租户实际存在的 11 种 `kpi_kind` 全是领料 / 损耗 / 盘亏三类。
它全部的采购足迹是 `material_batches` 上 **24 行、同一天（2026-08-08）**。

⇒ 公式的**两端都缺**，而原文说只缺一端。

**(d) 而且它整句作废了 —— 有一个数今天真的算得出来，它一个字没提。**

📏 prod 实测（MOCK_REST，2026-07-21~08-19）：

违反规范里的「**部分能做：能做的先给**，⛔ 不因为一半不行就整句作废」
和「不支持的指标 → 给**最接近的替代**」。

## 2. 三个选项

| | 做法 | 代价 | 判 |
|---|---|---|---|
| **A** | 只把假承诺删掉，改成诚实说明，**不给替代数** | 最小改动、零新增查询；但老板**仍然一个数都拿不到**，只是不再白跑一趟 | ❌ 仍然「整句作废」 |
| **B** | 删假承诺 **＋ 给最接近的替代**（领料成本占营收，带限定语），并说清真正缺的是什么、这一栏得**我们**先做 | 同一条 SQL 加一个 CTE，**0 次额外 round-trip**；风险是老板把 37.49% 读成食材成本率 ⇒ 靠限定语 + KPI 命名 + 一条阴性对照钉住 | ✅ **采纳** |
| **C** | 把 `fact_cost_line` 真正接上（从盘点/领料推期间耗用），把这个数**算出来** | 前提是「库存金额」这一列，而它**今天整个 schema 里不存在** —— 要 Java 侧录入 + ETL + 迁移，跨仓跨周期；且按形态 A⁹ 判据，接上之后它**仍然是估的**（理论用量 ≠ 实际耗用） | ❌ 不是本轮能做的 |

### 裁定理由

C 的前提不存在 —— 这不是「工作量大」，是**那份数据没有任何地方在产生**。
A 把一句假话换成一句真话，但它保留了队列 B 的本质（回了话、拿不到数）。
B 是唯一同时满足四条规范的：能做的先给 / 为什么另一半不能 / 老板要做什么 /
还能看什么。

### ⚠️ 「他自己要干什么」这一栏，本轮的正确答案是「**眼下没有**」

按形态 A⁹ 分两种 ESTIMATED：**(a) 可补的**（补了就实）、**(b) 结构性的**（补了还是估的）。
这一条是 (b)。owner 已经挂过账：**说清代价让他选，⛔ 不是推着他去做。**
⇒ 新文案明说「这一栏系统现在没地方记，得我们先做」，
⛔ **不再给他派任何活** —— 派一件做完也没用的活，正是这次要修掉的东西本身。
