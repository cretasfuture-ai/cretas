## 三 · 🔴 今天的缺陷证明：这里**恰恰需要那张词表**

### 症状（prod 实测 2/2 稳定）

问「最近30天各门店**菜品**毛利分别是多少」→ `dish_slot='菜品'` → 拒答 73 字：

> 最近30天没有找到「菜品」的门店销售记录，不能给出该菜的门店拆分，也不会用其他菜品或榜单替代。

只换那一个词问「各门店**水煮牛肉**毛利」→ **787 字，10 家门店全名齐**。

### 成因（我推翻过自己一次）

**第一版判断（错）**：「STORE_MARGIN 那条路没调目录闸」。
**推翻它的读数**：汇流闸 `dish_slot_after_catalogue_check`（`router:1519`）**存在**，
且在 `restaurant_intent_service.py:2482` 被调 —— 那条路**调了**。

**真因**在闸自己的承重条件上：

```python
if not ranking_direction:
    return dish_mention, None      # ← 「菜品」在这里被放行
```

它的 docstring 写着理由，而**那个理由是对的**：

> · 计划是点名一道菜（`ranking_direction is None`）⇒ 那个名字**就是题目**。
>   摘掉它就没题了，拿全菜榜顶替他点名的那道菜 = **替他改题**。
>   「香辣蟹煲卖得怎么样」必须留给定向拒答，⛔ 不许摘。

▎**「各门店菜品毛利」和「香辣蟹煲卖得怎么样」在这道闸眼里长得一模一样** ——
▎两者都是 `ranking_direction=None` **且**目录查不到。

### 而这两件事，目录**永远**分不开，词表**已经**分得开

【实测】`_DISH_GENERIC_TOKENS`（34 条）：

```
'菜品' ∈ 表 = True      '香辣蟹煲' ∈ 表 = False
'单品' ∈ 表 = True      '佛跳墙'   ∈ 表 = False
'菜'   ∈ 表 = True      '水煮牛肉' ∈ 表 = False
'门店' ∈ 表 = True      '最差'    ∈ 表 = False
```

⇒ **闸没问它。** 一句话的缺口。

## 四 · 判据订正：不是「词表 vs 查」，是「**闭集 vs 开集**」

原卡把分界定成 **「猜 vs 查」**，那一句是对的，但它**不足以**决定一张词表该不该退役。
今天补上第二刀：

| 被判的东西 | 集合形状 | 该用什么 | 例 |
|---|---|---|---|
| 这个名字**存不存在** | 菜名/店名是**开集**（老板随时上新菜） | **查**（目录） | 「香辣蟹煲」在不在菜单 |
| 这个词**是不是一个通名** | 通名是**闭集**（菜品/单品/产品/全部…） | **词表**（而且它已经对了） | 「菜品」不是一道菜的名字 |
| 老板要的**范围/意图** | 说法开放，但**目标枚举是闭的**（单店/全店/按店拆） | LLM 猜 + 能力表验 | 「各门店」要不要拆 |
| **指代/疑问**的语法角色 | 闭集 | 词表 | 「呢」「它」 |

▎**开集上用词表 = 永远补不全（「最差」那次）。**
▎**闭集上退役词表 = 把一件本来做得对的事拆掉。**

原卡自己的 `LEXICAL` 一栏已经写过同一句话（「『本月』就是『本月』，退役没意义」），
今天只是发现 `ENTITY` 那 17 张里**混着**两种形状。

## 五 · 原卡担心的那个代价，今天量出来了 —— **已经付过了**

原卡不做 A 的理由：

> 目录里查不到的菜名，现在是「查了没数据」，退役后会变成「我不认这个词」——
> 哪一种对老板更好，**要量，不能拍**。

【实测·prod，3/3 稳定】那个「变成」**已经是现状**：

> **菜单里没查到「腾椒鸡」这道菜**…也不会拿别的菜的榜单顶替。（后附全菜单）

而端到端复测线对它的判定是 **✅**：⛔ 不乱认、⛔ 不顶替、给了老板改错字的出路。

⇒ **那个代价不是「将来要付」，是已经付了、而且付得对。**
原卡的顾虑成立于它写的那天，今天不再成立 —— ⛔ 但这**不构成**做 A 的理由，
因为第一节已经证明 A 的前提本身不成立。

### B′ 的第一刀（⛔ 本卡不实现，登记待做）

`dish_slot_after_catalogue_check` 的 `ranking_direction is None` 那一支，
在**目录已经说「查不到」之后**再问一句「它是不是通名」：通名就摘（并照常发披露），
具体菜名维持定向拒答。

⚠️ 这**不是新增词表** —— 用的是已登记的 `_DISH_GENERIC_TOKENS`（词表棘轮零余量，
新增会当天弄红那道闸），也不改 `_catalogue_says_not_a_dish` 的语义。
⚠️ 承重断言必须有**两条**，⛔ 不是一条：
① 「各门店菜品毛利」不再拒答；② 「香辣蟹煲卖得怎么样」**逐字不变**（仍定向拒答）。
▎少了 ②，这一刀就退化成「拿全菜榜顶替他点名的菜」，那正是原设计要防的。

| 项 | 为什么 |
