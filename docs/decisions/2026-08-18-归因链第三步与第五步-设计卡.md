## 一、③ 步：上一棒把它整条写成「缺数据源」，而它有两半

例 14 原文：

```
③ 客流再拆（同比/环比；未来接百度地图客流做外部对照）
```

▎**分号前后是两件事。** 上一棒登记成「🔶 外部客流无源」，把分号**前面**那半
▎也一起判了缓刑。

### 1.1 读数：那一半需要的列，就在已经在读的那张表里

📏 **实测**（prod `smartbi_prod_db`，MOCK_REST，RLS 会话变量已贴出 `current_setting`）：

```
agg_daily     510 行 / 10 店 / 2026-06-29~2026-08-18 / bill_count 合计 101,768
```

`agg_daily.bill_count` **有列、有值**。而：

- 📏 `period_comparison` 的 `_agg()` **一次都没 SELECT 过 bill_count**
  （实测出参 `keys = ['cost_ratio','gross_margin_pct','revenue']`，
  `has_bill_count_key = False`）
- 📏 `store_comparison` **SELECT 了** `SUM(a.bill_count) AS order_count`
  —— 同一张表、同一个聚合，②（量价分解）用的就是它

⇒ **「客流同比/环比」缺的不是数据源，是没人去减那一下。**
⛔ 「缺外部客流数据源」这句话对分号后面那半成立，对前面那半不成立。

### 1.2 ③ 该挂在哪条路上：⛔ 不是 `period_comparison`

`period_comparison` 是**全链**口径，而且由关键词点亮
（`("同比","环比","较上期","较去年","增长率","下降率")`）。
📏 「我要不要关掉最差的那家店」一个词都不含 ⇒ 那条路上 ③ **永远不会出现**。

而例 14 的 ③ 紧跟在 ② 后面，拆的是 ② 算出来的**那家店**的**那个量**。

⇒ ③ 挂到**归因这条路**上，与 ② 同源（`store_comparison`），
   ⛔ 不新造第二条取数路径（形态 D）。

**做法**：`attribution` 这一维已经在调 `store_comparison(pool, fid, (start, end))`，
本轮**再调一次同一个函数**，窗口换成**前一个等长窗**。零新 SQL、零新数据源。

### 1.3 🔴 直接跳出来的一个已上线的错数

📏 **实测**（prod，MOCK_REST，直接调生产函数 `period_comparison`，窗口 2026-07-20~08-18）：

```
revenue.mom_pct = +42.0      mom_available = True
```

而同一批读数里：

```
current 窗   2026-07-20~08-18   30/30 天有数据   59,768 单   ¥21,482,197.83
mom 窗       2026-06-20~07-19   21/30 天有数据   42,000 单   ¥15,133,384.38
                                ^^^^^^^^^^^^^^ 租户数据 2026-06-29 才开始
按有营业的天数折算            199.3 单/天 vs 200.0 单/天   = -0.3%
                              ¥716,073/天 vs ¥720,637/天   = -0.6%
```

▎**「营收环比 +42%」全部由窗口覆盖造出来**，而它是被 `facts_index` 接地的、
▎老板问一句「这个月比上个月怎么样」就会看到的数。

⚠️ 这不是算错，是**问错**：拿 30 天的总额去比 21 天的总额。
⚠️ 而它已经上线了 —— ⛔ 所以 ③ 如果照抄这个形状去加「客流环比」，
   当天就会多产出一个 `+42%` 的假信号。**覆盖率闸不是 scope creep，是 ③ 成立的前提。**

### 1.4 覆盖不齐时怎么办：⛔ 不替他做判断

数据上分不清「那 9 天没营业」和「那 9 天没上传」——
事实表上两者**同一个长相**（都是没有行）。本仓已有这条登记。

⇒ 三个选项：

| | 做法 | 代价 |
|---|---|---|
| A | 覆盖不齐就整条不报 | 老板拿不到任何环比线索；而按天折算本来是能报的 |
| B | 只报按天折算的数 | 「关了 9 天」这种真实的总额下滑被抹平 —— 那正是他要知道的 |
| **C** | **总额 + 按天折算 + 天数，三个都报，并说明差在哪** | 多两个数；但**哪一个适用只有他知道**（那 9 天是关店还是没上传） |

**裁定：C。** 依据是北极星的取舍顺序 ——
▎**产品给依据和判断，决定是他的。** 抹平和隐瞒都是替他做判断。

**能让判据红的对照**：把 base 窗天数改成与 current 相同（都是 30/30）之后，
「天数不同」那一句必须**消失**，且总额增速与按天增速必须**相等**。
不相等 ⇒ 折算算错了。（用例 `test_equal_coverage_collapses_to_one_number`）

## 二、⑤ 步：样本结论成立，**不上线的理由不成立**

### 2.1 我自己重测的样本读数（⛔ 不照抄）

📏 **实测**（prod，我自己的普查探针，每租户**独立连接 + 会话级** `set_config`，
并逐条贴出 `current_setting`；阳性对照 = MOCK_REST 必须读出非零）：

```
agg_daily 里有数据的 factory_id: ['MOCK_REST']        ← 只有一家
MOCK_REST 等长窗(14d vs 前14d)每店客流变化: 全部落在 -0.9% ~ -0.8%
最差的一家: -0.9%
```

⇒ 「prod 上没有能触发『客流掉了』的样本」**成立**。上一棒这条读数是对的。

### 2.2 🔴 但上一棒的判据在量错的东西上（形态 A）

上一棒给 ⑤ 设的三条判据里，第 2 条是 `primary_cause == "客流"` ——
而 `primary_cause` 来自 `compute_store_attribution`，那是一个**横截面**的量：

```
它回答的是：这家店比【同行】少多少
⑤ 问的是  ：这家店【最近】是不是变了
```

▎**一家店常年比同行小，和「最近门口有没有施工」没有关系。**
▎横截面差距大恰恰是最不该问 ⑤ 的情况 —— 那是选址/店型，不是最近发生的事。

⇒ 判据本身瞄错了维度：

```
我想知道的 X：最近有没有发生什么（时间维）
上一棒量的 Y：它比同行低多少（横截面维）
```

而**时间维的信号今天在产品里根本不存在** —— 这正是 ③ 缺的那一半。

⇒ **⑤ 上不了线的真正原因不是「没有样本」，是「该给它把门的那个量还没造出来」。**
   ③ 是 ⑤ 的前置。这两步必须同一轮做，分开做哪一步都立不住。

### 2.3 ⑤ 分两层，⛔ 不是一个开关

owner 的原话是「它是整条链里唯一**承认**『有些原因数据里根本没有』的一步」。
**承认**是披露，不是告警。这两件事该分开：

| 层 | 是什么 | 什么时候出现 | 判据 |
|---|---|---|---|
| **⑤a 盲区披露** | 「这类事系统里没有数据，只有你知道」 | 跟着 ⑥ 那一段走，**不新增触发条件** | ⑥ 的四道门（已有） |
| **⑤b 具名反问** | 「X 店最近 7 天客流比前 7 天少了 12%（每天少 25 单）——这段时间门口/商场有没有变化？」 | ③ 读出**真的掉了**才出现 | ⑤a 的门 + ③ 有效 + 跌幅过阈值 |

### 2.4 为什么 ⑤a 可以无条件跟着 ⑥ 走（而这不违反反目标）

反目标那句话是针对**误发的提示**：断言了一件经不起他去查的事。

▎**⑤a 一个字都没有断言。** 它说的是「这一类我看不见」——
▎这句话**永远为真**，不存在「他去查发现一无所获」的可能。
▎一个问题的失败模式是无聊，不是失信。

而更硬的理由是：**⑦ 现在正在说的话是不完整的。** 已上线的 ⑦ 原文：

```
上面这些都查过、还是解释不了，才轮到怀疑「这家店自己的运营」（服务、出品、人手）
```

它把「数据查完」之后剩下的解释**枚举成了运营一种**。而线下现实变化同样还剩着，
且产品**永远看不到它**。⇒ ⑤a 不是往答案里加东西，
**它是在补一句已经印出去的话里漏掉的那一档** —— 缺了它，⑦ 是一句略微过头的话。

⚠️ 所以 ⑤a 的正确落点是**并进 ⑦ 那一句**，⛔ 不是再起一段。
   起一段就真成了「每次都说」的废话。

### 2.5 ⑤b 的阈值：⛔ 现在不拍一个数

📏 唯一有数据的租户全店落在 -0.9% ~ -0.8%，**没有分布可拟合**。

⇒ 阈值取 **-10%**，理由**不是**从这份数据拟合的（拟合不出来），而是：
- 它必须**明显高于**本租户的噪声带（±1%）—— 否则在唯一能跑的租户上天天误发；
- 它必须是老板**说得出口**的量级：「少了一成」是他会去问店长的事，
  「少了 3%」不是。

⚠️ **这个数是拍的，我把它标出来**（形态：代理判据要标出来并且能被替换）。
   解冻条件：出现第二个有数据的租户之后，用真实分布重定，⛔ 不要在这之前微调。

### 2.6 ⑤b 在 prod 上**验收不了**，这是已知代价

📏 MOCK_REST 最深的一次 14 天等长窗跌幅是 **-0.9%**，阈值 -10% ⇒ **恒不触发**。

⛔ 我**不会**为了能演示而把阈值调到 -0.5% —— 那就是「为只有种子数据支持的形状
   建检测器」，而且会在唯一的租户上天天发一条经不起查的提示。

⇒ 交付里 ⑤b 的证据是：单测（含变异）+ **一次真实 prod 跑**证明它**正确地闭嘴**。
   它的正文长什么样，登记为**未在 prod 验收**。

⚠️ 形态 B⁴ 的直接应用：**在 MOCK_REST 上「不触发」不能证明任何事**，
   因为它的输入由构造落在阈值之外。所以 ⑤b 的「能红」由变异对照证明，
   ⛔ 不由 prod 的沉默证明。

## 三、三个选项（整轮）

| | 做法 | 代价 | 裁定 |
|---|---|---|---|
| A | 只做 ⑤a（盲区披露），③ 继续挂账 | ⑤a 只能说一句泛泛的话，说不出「哪家店、掉了多少」；<br>而 ⑤b 永远没有前置 | ❌ |
| B | 只做 ③（客流同比/环比），⑤ 继续挂账 | 多了一个数，但**没有出口** —— 老板看到「客流掉了 12%」之后，<br>产品下一句仍然直接跳到「怀疑运营」 | ❌ |

上一棒 ⑦ 的病（它把剩下的解释枚举成了运营一种）。分开做，两边都立不住。

## 四补 · 🔴 prod A/B 当场抓到一个**我自己引入的**错数

⚠️ 值得单独记：**单测抓不到**，只有在真实答案里和 LLM 正文并排看才看得见。
它和上一棒 7.5 节那处自相矛盾是同一个位置上的同一类事故。

### 4.1 读数

第一版把 ③ 的数字写进了 prompt（`## 客流趋势 … 每天 199.3 单 / 上一周期每天 200.0 单`）。
📏 prod A/B（MOCK_REST，各 3 轮，真实入口，绕过叙述缓存，阳性对照
`_build_prompt 1 次 / 门店行 20` 逐轮核对）：

| | BEFORE（等价 main） | AFTER 第一版 |
|---|---|---|
| 正文出现「每天」 | **0/3** | **3/3** |
| 其中**用错**的 | — | **1/3** |

那一句原文：

```
「它营业额垫底，但每天只比平均少卖 29,131 元…」
                  ^^^^^^^^^^^^^^^^^^^^^^^  ¥29,131 是【30 天】的差额
```

▎**我给了模型一个新词，它把这个词安到了另一个数上。**
▎而 `delta_revenue` **不在 `to_facts_index()` 里** ⇒ 它是个没有名字的派生数，
▎接地闸结构上够不着它 —— 与上一棒那个「59 万」逐字同形。

### 4.2 裁定：③ 的数改**确定性渲染**，prompt 里只留结论词

这不是新裁定，是上一棒给 ⑥ 下的那条**我没有一次性执行到位**：

▎**能确定性算出来的东西，⛔ 不要交给模型说** ——
▎那等于把「说不说」和「说得对不对」一起交出去。

⇒ `_append_traffic_trend`（接地闸**之后**的确定性追加，与 ⑥ 同形状）。
⇒ prompt 那一段只给**结论词**（`明显下降` / `没有明显下降` / `算不出来`），
   ⛔ 一个数字都不给 —— 有一条断言扫那一段里有没有数字（变异 M12 拿回数字就红）。
⚠️ 但**不能什么都不说**：沉默会让模型继续拿横截面的「客流跟其他店差不多」
   去回答一个时间维的问题。

### 4.3 修完之后的读数

📏 同一条命令、同一个租户、3 轮：

| | 第一版 | 最终版 |
|---|---|---|
| 「每天」用错 | 1/3 | **0/3** |
| ③ 的数进老板那一屏 | 0/3（模型没说） | **3/3，逐字相同** |
| ⑤a 出现 | 3/3 | **3/3** |

而 LLM 正文里那句话也跟着变了 —— 这是 ③ 真正的收益：

```
BEFORE：「不是没人来（客流跟其他店几乎一样）」   ← 横截面，答的不是这个问题
最终版：「客流没掉」                              ← 时间维，这才是 ③ 问的
```

## 七、这一轮给下一棒的一句话

▎**⑤ 之所以三棒都没做成，不是因为「没有能触发的样本」，**
▎**是因为该给它把门的那个量（③）一直不存在。**
▎一步缺席会让它下游那步看起来「没有需求」——
▎而上一棒把 ③ 整条登记成「缺外部数据源」，正好把那个量判了缓刑。
