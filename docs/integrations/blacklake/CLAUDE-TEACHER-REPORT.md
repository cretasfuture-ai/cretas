## 实际提炼与修正

1. **统计口径**：提醒条数、材料行数、唯一工单数、任务数与报工数不能互换、相加或直接相减。代表提醒的比率不能外推整个工厂。
2. **样本选择**：能算成本的子集可能集中在某些产品、阶段或批量。先解释覆盖与缺失，不能把子集当成全厂平均。
3. **成本差异**：先拆材料和人工，再区分每件耗用量、每公斤材料的账面折算值、材料组合与加工阶段；零工资不能直接当低成本基准。
4. **指标释义**：`inputKindsChanged` 是布尔标记，不是改变物料数量；`inputValuationChange` 已经是单位估值变化，不能再除一次数量变化。`sameUnitAmountRank` 是加权单位直接成本排名，不是总金额排名。
5. **程序补算**：同一对可比工单的 KG 材料每成品账面净额变化 =（1 + 每成品 KG 耗量变化）×（1 + 每 KG 账面折算值变化）− 1。仅覆盖 KG 材料，不包含其他单位材料、人工或制造费用；不解释为采购价涨幅。
6. **单位与流转**：换算或批次未验证时，投入产出比无论高低都不能当损耗证据；有关联号不代表批次数量与成本已经贯通。
7. **期间与库存**：完工工单全生命周期成本、期间业务日期出入库、采集时点余额分别解释。无历史期初期末余额时，只提示缺口，不倒推关账。

保留了教师的错误及更正记录。例如，早期教师把单位估值变化当总金额变化，再除用量变化；源码释义复核后已纠正。模型多数意见不能覆盖程序定义。长文摘要同样是待核验素材，不直接成为业务异常结论。
