## 界面与追问

入口仍为 `http://127.0.0.1:5178/blacklake-smartbi.html`。没有新建另一个业务页面；数据板块下新增醒目的分析区：成品核算、产品成本、加工人工、原料投入、生产、库存和数据覆盖。默认先看 16 张可核算工单；可以切换查看全部待补工单。人工另有实际数据表。

每个区域显示观察、待验证假设、下一步；计算口径、限制和证据引用可展开。每块独立保留最近 6 条追问消息，工厂/用户/角色/归档/板块变化时清空并拒绝迟到回答。服务端只读取当前授权归档，过期 run 返回 409，不信任客户端历史中的事实。

`POST /api/smartbi/blacklake/sections/followup` 接受 `section_id / question / run_id / history`。这是当前板块的证据解释与核对，不是任意开放式经营问答，也不执行修改。问题和历史不发给模型；计算、观察与缺口由确定性证据回答，27B 只从匿名代表事实选择合法核对动作。无法从证据确定原因时明确说明。

当前使用 `qwen3.8:27b`，旧 8B 缓存不再作为当前解读。27B 的结果由 DPAPI 保存，绑定完整规则指纹、事实和模型，变更/损坏后不附加旧解读。每板块独立核验代表事实覆盖：0 条为 not_applicable，部分为 partial，精确覆盖才 complete；不借用全局完成状态。当前七板块的代表事实覆盖分别为 11/11、5/5、4/4、5/5、4/4、3/3、5/5，类别有重叠，不可相加为独立问题数，也不代表逐单根因已确认。
