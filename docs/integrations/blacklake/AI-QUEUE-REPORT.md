## 用量记录

Ollama 官方响应的 `prompt_eval_count`、`eval_count`、`total_duration` 分别作为输入 token、输出 token、模型耗时；两项 token 都存在时才计算合计。缺失为 `null`，不伪造为零，不用字符数估算。定义参见 [Ollama Chat API](https://docs.ollama.com/api/chat)。

本地 `inference_usage` 记录调用 ID、哈希租户/用户、模型、排队时间、起止时间、返回/失败状态、实际 token 与耗时；不保存提示词、回答、工单、人员、工资、金额或认证材料。`returned` 表示推理端返回，不替代业务输出校验；无效 JSON 仍保留已返回的实际 token，传输失败而没有计数时记未知。

用量同报告一起保存，页面显示“本报告 AI 用量”。原用量与本次请求用量区分；共享缓存命中的 `currentRequestUsage` 为零。旧报告无计数时显示“历史未记录”，不会倒推或补造历史用量。汇总以唯一调用 ID 的台账为准，不能把多个复用报告的原用量重复相加。
