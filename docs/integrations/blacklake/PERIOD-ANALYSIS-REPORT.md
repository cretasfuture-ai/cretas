## 页面行为

- 支持日、自然周、月、季度、年和任意连续日期，含首尾日期，统一北京时间。默认昨天，可回到“全部已采集”。自然周期快捷按钮以当前结束日期为参照，日期框可直接调整。
- 默认按工单实际完工日期归属；可明确切换工单创建日期。缺少对应日期的工单单独计数，不猜测分配。按完工筛选得到的工单集不再显示误导性的“完成率 100%”。
- 数值与异常事实先读取，再提交后台分析；等待 AI 时可以切换日期。各数据板块下面保留独立分析、中文证据、问题工单和追问。
- 规则结果先保存；本地 27B 限流或忙碌时，保留等待状态、显示下一次重试，不把规则结果冒充 AI 已完成。
- 同工厂、来源、日期、归属口径、时区、事实指纹和规则版本复用报告；数据变化或主动重算生成新版本。历史抽屉保留原周期，不替换当前表格。
- 参考已完成的兼容历史报告，区分旧版本、相邻前期、范围内子周期。不会将重叠报告金额叠加，不平均子报告单位成本；没有可比历史就明确说明，异常未再触发不等于已解决。

## 夜间计划

用户明确不要早上；所有触发均为 `Asia/Shanghai` **23:55**：

| 触发日 | 生成范围 |
| --- | --- |
| 每晚 | 当天预览、前一天补齐版 |
| 周日晚上 | 本周预览 |
| 周一晚上 | 上周补齐版 |
| 月、季、年最后一天晚上 | 当期预览 |
| 下期第一天晚上 | 上期补齐版 |

“补齐版”是对已同步数据重新计算，不能保证源端完整。23:55 后发生或后续补录的数据由后续快照触发新版本。已有报告不会被覆盖。

隔离适配服务的生命周期内每分钟检查到期任务；已启用真实测试运行。服务必须保持运行，停机后从持久检查点分段补跑，首次启用回看两天。新来源快照和规则版本会逐批复核已保存范围。这里没有安装操作系统开机服务，也没有改变已有黑湖同步任务的启停状态；报告定时器不会自动刷新黑湖源数据。

## 成本与库存口径

选中日期决定哪些工单进入分析，随后读取这些工单在当前快照中的完整生命周期领料、退料和累计工资，包括跨天记录。这是所选工单的可识别直接成本，**不是期间发生费用或当时已知的历史关账结果**。任务工资与报工估算不重复计算；半成品上游成本不能重复叠加；缺失金额不填零。

出入库发生统计单独按 `bizAt`；缺日期的单据单列。当前库存余额仅当采集时点在所选范围内才可展示，并明确它是采集时点余额；历史范围没有历史余额时显示缺失，不能解释为零库存。金额币种、原料批次贯通、制造费用仍有缺口，不推算完整制造成本或毛利。
