## 页面变化

- 金额、数量、比例及图表提示最多展示两位小数，保留计算和来源原始精度；编号、计数、日期不当作金额处理。
- “本段分析”改为“这组数据的分析”。每组写明覆盖范围：本次完整采集快照；成本只对资料具备的工单计算。文字不随图表单位、搜索和表格筛选重算，已明确提示。
- 证据引用显示中文来源说明；材料、工序证据可展开查看真实业务单号、数量、单价、金额。零与未提供分开。内部规则 ID 仍用于绑定，不作为可读说明。
- 报告、提醒和助手回答改为较直接的中文。用户原问题、对话历史及来源事实不被文案转换改变。
- 工单红色标识暂不能核算；黄色标识可核算但有核对提醒。提醒与缺口不相加重复计数。分析卡、异常明细和工单表均可定位真实工单，在抽屉中核对具体问题及原料明细。
- 深层差额面板原先仍按产品编码和单位混合不同名称/生产阶段。现按原工单明细检查一致性并排除冲突组，文字分析同步排除；未改变工单金额或把不同阶段成本相加。本次排除一组。
- 旧生产 SectionInsight 仅增加 `as const` 类型约束以修复实际完整类型检查发现的问题，运行代码不变；生产路由继续使用旧页面。测试专用组件和本机自动登录入口不进入默认构建。
