## 成本结果与口径

当前 109 张工单、91 张完工；301 个任务、272 条报工、332 张出入库单。生产领退料筛选已审批状态1及业务类型30/32，共145行；143行同时通过工单ID、编号和关联类型10校验，另2行未关联。

143行中143行材料金额有值，**74行是源端零值（51.75%）**，不能称为免费原料或已验证财务成本。301个任务的累计工资有值，不重复叠加报工预计工资。最终仅 **16/109张（14.68%）** 工单具备展示单位可识别直接成本的条件；其余逐单列出阻断原因。

单位可识别直接成本 = （已关联领料成本 − 已关联退料成本 + 任务累计工资）/ 工单层成品良品量。只用于已完工、正成品量、有单位、材料与人工字段齐备、无估值/关联异常的工单。即使可展示，也只代表来源中可识别的两项直接成本，尚未核实币种，不是结算成本或毛利。

以下情况阻断单位成本：缺材料或工资；非零领/退数量的金额或单价为零/缺失；数量与金额符号冲突；零数量却有金额；负单价/负工资；任一正工时工序工资为零；有成品但材料净额非正；候选工单存在领退料关联缺失/冲突。冲突行同时阻断ID与编号两侧候选工单，不把未关联费用丢弃后继续当完整成本。重复工单号或重复/缺失领退料明细ID使数据集分析失败。

原料消耗按物料代码与单位分别保留；成品量取工单良品，不跨工序求和；BOM与尚未独立验证父级的225条工单用料不替代实际消耗。质量、计划/实际、库存汇总任一必要值缺失时不把部分和当全量，显示名相同但稳定代码不同的产品/仓库不合并。

- 实际API验收：真实Java登录与工厂归属通过；无登录401、跨工厂403、viewer成本访问403、写方法405；未设scope、错租户、错来源工厂均0行；运行角色写权限为false。
- 自动测试、TypeScript检查、测试构建及真实浏览器结果与最终内容哈希见 SMARTBI-VALIDATION.json。真实浏览器覆盖成本明细、生产图表、库存、13类覆盖以及390px窄屏；控制台/页面错误0、HTTP失败0、业务写入0。
