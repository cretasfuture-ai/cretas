## 安全与测试交付

- 认证材料在本机窗口输入，Windows CurrentUser DPAPI 保存于仓库之外；正式业务响应与完整 BI 报告也仅留本机加密证据。tracked 文件不含真实手机号、密码、哈希、Token、来源 orgId、人员明细或工资金额。
- 后续业务查询先读取独立的本机来源绑定，再与登录来源比较；不能因换账号而自动重新认领来源工厂。
- 真实数据使用单独密码保护的 PostgreSQL/Redis，只绑定 127.0.0.1。数据库运行角色无 superuser/BYPASSRLS，四表 FORCE RLS；测试接入默认拒绝非本机/非专用 PoC 数据库。
- 测试容器保留以供核查，未停止任何其他任务服务。Docker 管理员可管理测试服务及数据；这不是针对本机管理员的隔离边界。未进行服务器生产发布。
- `python -m blacklake.test_local` 使用新的合成数据库、真实 PostgreSQL SCRAM 密码认证和真实受密码保护的 Redis；最终通过数、退出码、零 skip 与内容哈希写入 VALIDATION.json。覆盖事务失败回滚/恢复、幂等、跨租户/跨工厂 RLS、401 单次刷新、只读白名单、滚动限流、错误分页、错误期间过滤、数值篡改检测和跨期间成本回归。
- 独立风险复核提出的来源固定、期间成本过滤、初始化半成功、对账时间边界、Redis 连接保护等问题已修正。测试资源复用必须实际通过 readiness，不能仅凭证据文件存在判成功。
