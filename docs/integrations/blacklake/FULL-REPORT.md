## 使用与恢复

在 `backend/python` 下运行：

```powershell
python -m blacklake.full_pull --install
python -m blacklake.full_pull --resume
python -m blacklake.full_verify
```

首次命令显式安装本机测试归档表并开始一次新扫描；已有运行使用 resume。连接、账号及来源绑定沿用 README 的仓库外加密配置，不在命令行传密码。运行前检查测试容器身份、受限数据库角色、列结构、复合主键、精确隔离策略及 RLS/授权。仅对本机测试库安装 `002_full_snapshot.sql`。

断点绑定账号、租户/来源、响应合同及校验版本；任一变化拒绝复用。首次真实扫描在版本 2 加固前完成，已用 `full_verify` 对留存原文离线复验，无新增源请求；旧断点不升级为版本 2，也不允许新规则静默跳过旧分区。需要新扫描时使用不带 resume 的命令，保留旧证据。

`full_probe` 是结构发现工具，任一探测失败返回非零；早期无过滤 BOM 查询失败属于已记录的契约发现，最终使用逐产品查询成功，不作为失败接口已验收的证据。
