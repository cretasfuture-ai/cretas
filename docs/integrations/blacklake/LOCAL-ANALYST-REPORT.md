# SmartBI 本地经营解读交付

2026-11-04；Base `22373115674bada487f6e1a16c8090bff23d8be8`；Owner Codex/root；本机隔离测试、草稿 PR #1390。

## 用户需要的能力

原本本地模型只从告警中选择核对动作与优先级。本轮新增指标课程、匿名证据准备、完整结构化解读与业务矛盾检查。业务规范见 [ANALYST-PLAYBOOK.md](ANALYST-PLAYBOOK.md)，代码真值为 `analysis_playbook.py`。

每个适用板块必须包含统计依据、怎么看、为何重要、待验证原因、责任人与下一步、不能下的结论、后续问题。模型选择统计和解释，程序负责精确算账及真实名称、工单、金额绑定。七个板块为覆盖、材料、人工、成品、产品成本、生产、库存。

覆盖低价但缺主料、只见包装、零工资对照、人工占比虚高、名称/阶段冲突、样本不足、周期未齐、历史余额缺失、跨周期重复统计等误判场景。它是可版本化、可回归的经营分析方法，不是把六膳门的工单号和现成结论写进 prompt。

## 工程接入

- `analysis_playbook.py`：指标定义、公式、阅读方式、风险课程与提示词。
- `analysis_evidence.py`：构建匿名统计与独立的可读证据映射；逐板块列出允许与必需引用，保持名称冲突组不可比。
- `local_analyst.py`：模型生成解读、覆盖和证据校验、业务矛盾检查、一次自修复、版本化缓存和 token 归集。
- 原共享 `alert_local_ai.enrich` 在运营配置 `SMARTBI_LOCAL_ANALYST_ENABLED=1` 下启用新框架，Excel、API、已存数据沿用已有权限链。模型和框架不能由请求者自行切换。
- Excel/API 工单表从已通过原有字段、重复工单和数值门禁的行计算加权成本统计，按产品、单位、名称分组；不把每单单价直接平均。派生成本统计在无价格权限或成本范围受限时一起移除，不能借新解读泄露成本。
- 隔离黑湖适配服务启用新框架，周期任务保留持久队列；显式查看旧分析版本时生成新 revision，旧 ready 不覆盖。空范围和未配置模型的报告不会因版本检查无限重建。
- 七个数据板块展示真实本地模型解读、统计、待验证假设、不能下的结论与动作；追问复用同范围、同事实、同工厂且已验证的解读，继续保留原计算口径。

## 隐私与事实边界

模型输入仅为匿名统计、比例、风险类型和允许动作，不包含原始工单、产品名称、人员、工资明细、实际金额、自由问题或认证材料。真实名称与金额在模型输出后绑定。输出中的任意数字、未知或跨板块证据、漏板块、漏必需风险及明显因果断言都会被拒绝；修复失败保留规则结果并明确 AI 未完成。

额外检查“已知有出入库流水，却声称没有流水”的业务矛盾。缺历史期末余额不等于缺流水；部分工单缺失不能扩大成全厂结论。结构校验不能证明所有自然语言解释都正确，仍需业务核对与持续样例回归。
