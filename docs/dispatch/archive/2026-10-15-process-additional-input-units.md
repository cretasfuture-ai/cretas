# Workflow upstream and additional-material units

- Scope: shared `ProcessSheetServiceImpl` input normalization, `processSheetUnits.ts`, and their focused regression tests. Separate from platform-only continuation changes; no Entity, Repository, query or migration changes.
- Reproduction: the synthetic test factory published a Workflow with dough in kg plus a separately counted packaging input. The production UI rejected the entire sheet because the two port units differed. Structured backend submission had the same aggregation restriction.
- Contract: when a process has upstream semi-finished/finished inputs, its group input quantity and yield denominator use those upstream ports. Additional RAW ports retain their individual units and quantities; they are never added to that denominator. Processes with only RAW inputs still reject heterogeneous physical dimensions; heterogeneous upstream inputs still reject. Every port retains unit/SKU/selection validation.
- Explicit batch inputs now validate and fill the authoritative port unit. Both raw-allocation submission paths preserve a declared positive upstream quantity and unit; missing upstream quantity fails closed instead of deriving kg from packaging counts. Existing RAW-only allocation derivation remains unchanged.
- Backend: `ProcessSheetAdditionalInputUnitsContractTest` plus `ProcessSheetWorkflowUnitNormalizationTest`: 22 tests, 0 failures/errors, BUILD SUCCESS. Tests cover kg upstream + counted bags, missing/wrong units, unauthorized SKU, explicit RawInput, missing denominator and both submission branch connections. Initial real behavior regression: 1 assertion failure, 0 errors; an intermediate test also caught selecting the first RAW unit after filtering.
- Frontend: `processSheetUnits.spec.ts` and mounted `ProcessDataTable.workflowContext.spec.ts`: 36 passed. Initial added positive case failed with the actual mixed-input error, then passed after the fix. Source-reading backend gate ends in ContractTest and is selected by Java Gate.
- Private evidence: `Documents/assembly-integration-assessment-20261015/process-additional-units-red.log`, `process-additional-units-verified.log`, `target-ui/additional-input-units-{red,green}.log`. No credentials or customer data committed. Final UI readback and exact-head CI are separate evidence recorded in the platform closure report.
- Production untouched. This does not introduce cross-dimensional conversion or add packaging quantities to mass totals.
