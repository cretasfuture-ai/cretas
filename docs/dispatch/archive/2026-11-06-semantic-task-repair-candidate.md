# 意图与多轮任务修复候选（PR1476）

本批是候选代码及验证交付，不是生产发布或独立多轮验收完成证明。保持草稿、Owner/scope、用户冻结与发布门禁；不训练、不替换线上模型、不补生产意图绑定、不进行生产业务写入/重启/部署。

## 实际链路与范围

RN/Web → 普通/SSE Controller → Facade → 现有服务端会话快照 → 既有任务修复 → AIIntentService/Python 意图决策及本地召回/分类 → 权限与模式校验 → ToolDispatch 参数解析/绑定 → Tool/Skill → 业务服务 → 现有状态更新。

这里的 resolver 各有职责：Python 决策选择路由；QueryPreprocessor/实体指代负责引用与时间；FollowUpResolver、SlotAnswerRule 保留原有追问；新的无状态 ConversationTaskRepairSupport 协调任务动作，原 ConversationService/ConversationMemory 保持状态所有权；ToolDispatch 合并参数、绑定真实对象并调用已有 Tool。没有 IntentHandler 或第二套任务状态库。

生产只读刷新已证实 Java 仍启用 Python matcher，工厂名单空值，Python FACTORY 决策/rerank 开关保持；部署 JAR 没有本 PR 的新增会话类。槽位在其他发布后发生变化，不能把旧快照的 green 槽视为当前固定 active，也不能把本地候选链当成线上已生效。精确部署 Git SHA 仍未知。

## 准入、上下文与来源

- NEW/PRESENT/EXPIRED/UNKNOWN 分开；读取失败不当成全新请求。完成任务及结果引用、页面对象、草稿、提交动作、历史和归属均参与直达判断。
- 已审核意图标签不等于该表达已获独立请求直达审批。相关上下文/未知状态时，精确表仅提供候选；Java 短语、缓存和自由文本显式 intentCode 同受准入。合法确定性 UI 选择仍受主体、权限和执行门禁。
- 普通/SSE 共用参考时点、有效目标、受控用户历史、参数来源、待答字段和任务/结果引用。助手业务表格不外发；服务端真实 ID 留本地，模型选择不透明结果引用。
- 本轮明确修改优先；此前兼容值保留；默认值晚补。模型重复输出的无依据数字仅在精确等于程序默认值时丢弃，不能覆盖已确认值或接受另一猜值。

## 状态、确认与能力

- 已填参数允许纠正，数量无单位时可保留经现有 UnitContractService 校验的已确认单位；显式不兼容单位及模型篡改单位被拒绝。
- 暂停使用原 ConversationSession.PAUSED；恢复不执行 Tool。多个暂停对象不随机选择；查询后恢复需要当前原话依据、真实 READ 成功及原草稿版本仍有效。
- 模型等待在事务外；actor 锁、行锁/refresh 和版本 CAS 在短事务内。旧请求、迟到结果、已取消任务不能复活。Memory-only 只读会话仍可正常工作。
- 当前只读继续保留原 Memory session/版本，不因任务修复再次刷新而变成新会话。历史已提交动作与真实当前 read 可以共存；仅 committed-only 的草稿修订被拒绝。
- 确认票绑定具体草稿、修订和业务参数。票失效与草稿变化同一事务；不影响其他草稿；执行中的票不得修订；已提交业务不能假装只是修改草稿。
- 排行 Tool 固定按金额，数量指标不能偷换为金额榜。所查生产配置未证明排行/订单详情意图已绑定；没有顺手补配置。待发货不是现有 Tool 定义的单一订单状态，不发明状态映射；“已确认订单”的开发回归不等于验证了待发货口径。
- 订单列表反馈真实 ID；详情引用重新按当前权限绑定，只走 canonical ID 查询，结果 ID 不符不展示。生产配置未证实详情绑定，本地受控两步不能冒充生产接线。
