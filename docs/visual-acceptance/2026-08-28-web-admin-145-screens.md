## 🔴 「查不到就编一个数」的**真因链**被走查串起来了

078 财务概览「本月交易笔数 **0**」而正下方「交易记录 共 **32** 条」——

```
① 视觉验收看到同屏矛盾
② 跨语言字段闸的基线里**正好有这一条**
     views/finance/costs/index.vue :: overview.monthlyTransactionCount
③ 代码确证: 后端 getFinanceOverview **从不 put 这个 key** ⇒ `undefined || 0` ⇒ 0
④ 而**同一个方法里**已经有一段注释记着完全同一形态的上一次:
     「payableCount/receivableCount were never populated here — FE reads `|| 0`,
       so the stat **silently showed 0** regardless of real data」
   那次修了两个字段, 这三个漏了。
```

▎**`|| 0` 是今天贯穿始终的那个动作**: 033 编 100 / 072 编 345 / 080 编 0.00 / 078 编 0。

### ⛔ 量过两次做不出可信判据的那道闸 —— **没有造**

`undefined 天后` 本该被 #253 的跨语言字段闸抓到, 它漏了(只跟踪从 `res.data` 直接赋值的变量,
跟踪不到表格行参数 `row`)。扩面:

```
不加误报过滤 → 35 条, 63% 是前端自造的 UI 状态 (laborExpanded / mixExpanded…)
加误报过滤   → 13 条, 但**把 daysUntilMaintenance 本身滤掉了** ——
               过滤判据是「script 里有 `fld:` ⇒ 前端自造」, 而那里有
               `daysUntilMaintenance: 0` 这个**默认值**,
               而**前端给默认值恰恰是因为后端不产出**。
```

▎不过滤会被关掉, 加过滤会把真缺陷滤掉。**做不出可信判据, 就不造那道闸。**
