## 发现与修复

真实订单收款页原显示未税109.73元为收款总额，但报价及发票含税金额为124元；后端登记上限、财务核销后的结清判断和订单派生收款状态也使用未税值，导致合法124元被拒绝、到账超过109.73元时被提前标记结清。

统一复用已有`SalesOrder.getPayableAmount()`，即未税总额减折扣加税额。订单页和财务录入页显示“应收总额（含税）”，余额共用两位小数计算，避免`124-8.04`生成`115.96000000000001`导致余款被误拒。未改实际收款金额、核销分配、租户过滤、库存、发票创建、Entity映射、Repository查询或迁移。
