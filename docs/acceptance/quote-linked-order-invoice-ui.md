## 实际闭环与修复

订单为2个成品、含税报价62.00元/个；原待审核发票未税109.73元、税14.27元、合计124.00元。在真实订单“开票记录”页面填写审核备注并通过，再选择本地合成PDF确认开具。数据库记录REQUESTED→APPROVED→ISSUED，保留审核人、审核时间、备注、出具时间及文件名；订单已开票金额124.00元、状态FULLY_INVOICED。刷新页面可读回原记录。

真实点击下载发现私有OSS返回AccessDenied。修复为受保护的`GET /finance/invoices/{invoiceId}/download-url`：按工厂取得发票，校验源订单存在、同厂与createdBy行级数据范围；仅ISSUED且有PDF时生成300秒临时签名，响应no-store。订单页和财务开票页共用点击取新链接组件，失败关闭空白页并明确提示，可重试；不持久化短链，不再直连原始私有URL。订单页同时明确标注“订单未税总额/已开票（含税）”，避免109.73与124.00比较产生歧义。

未改审核、出具、金额、库存业务逻辑，无Entity、Repository方法/查询、迁移、权限配置变更。三个既有测试只适配控制器新增依赖。
