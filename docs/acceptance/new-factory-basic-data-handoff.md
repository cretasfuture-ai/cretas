## 本批补验及代码边界

本批唯一私有场景表为 `assembly-integration-assessment-20261015/target-ui/basics-delivery-scenarios.md`。只复用原隔离新厂和环境；没有重建库、重新跑完整采购/生产、重验已完成权限切片或访问生产。

新增基础配置只有两条成品包装规格；既有三个默认仓映射通过真实UI保存和刷新核对，值不变。发现并修复的共享业务问题为新建销售页无法读取/明确选择具体箱规，单独PR交付。平台增量仅增加已应用蓝图及成功结果页的交付指引，不读取或伪造“已全部配置”状态，不引入工厂账号到平台页面的授权。

实际业务正向对照为独立测试销售草稿：1箱，箱规2，factor60，baseUnit个，DRAFT。未进行确认、审批、预留、发货、开票或收款。独立读回确认库存、旧订单、计划、BOM、Workflow不变；其他工厂相关15表指纹一致。

交付指引在真实平台账号恢复已有APPLIED蓝图后可见且仅一份；无需重新访谈、重新应用蓝图或创建新厂。未应用状态不显示该应用后提示，组件/真实条件挂载测试覆盖。

## 验证与保留边界

本批开发只跑相关测试：销售选择/序列化/价格兼容31项，平台交付提示与既有续编入口12项。最后选择器类型修正后仅复验6项；源码冻结后前端类型检查和生产构建通过（Vite1m45s），以各PR精确head实际CI结果决定手动合并。不新增后端/JPA/迁移，不用重新Java全量替代本批前端验证。

完整私有证据含截图、页面请求摘要、数据库读回及断言，保存在现有证据根目录；提交内容仅本脱敏清单、归档说明和代码/测试。历史测试失败、故意注入的503及本地无关SmartBI摘要401分别保留，不把它们改写成全站全通过。

这张清单完成的是基础资料交付边界与本批缺口，不是生产建厂启用、真实资金、全岗位权限、全部业务或移动端验收。生产启用前的V63恢复方案等整体门槛仍独立保留。
