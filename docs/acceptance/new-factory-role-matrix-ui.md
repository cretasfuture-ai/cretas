## 本批修复

新厂的L1只有少量明确配置时，后端按“工厂覆盖→平台配置→后端角色默认值”允许采购，但前端只合并前两层，真实采购账号被送到403。直接补前端默认矩阵还会把销售多余的生产/仓储/财务/分析权限带入正常加载路径。

新增只读当前账号有效权限接口。只接受JWT建立的工厂身份，拒绝平台身份与跨厂，按自身ID重新读取当前有效且未删除的同厂账号，再调用既有严格权限解析器。前端读取此快照，保留明确禁用、只读、身份响应隔离及加载去重；加载失败拒绝访问并允许立即重试。没有修改任何全局L1、工厂L2、行级策略、Entity、Repository查询或迁移。

餐饮五个既有细分部门仅在服务端缺该部门键时保留原角色细分，始终受服务端餐饮总上限约束；不以此补回其他业务模块。异步加载后的七种餐饮角色、明确部门配置及FACTORY过滤有专门回归测试。此处是防止共享权限修复影响既有功能，不是新增餐饮能力。

旧静态分支分析器显式隔离网络加载，保留原本按本地默认矩阵测量的模型；真实守卫、权限谓词、断言和覆盖预算未削弱。实际接口失败拒绝由权限加载测试覆盖。
