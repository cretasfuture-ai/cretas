# 生产与财务行级过滤验收（2026-10-18）

后续增量：[收货任务入口行级权限验收](receiving-task-row-scope-ui.md)，已补齐本文保留的受限生产页共享收货角标与列表边界。

承接 [Web 首版清单](factory-assembly-web-first-closure.md) 的受限入口拒绝基线。本批已连接的生产计划、应收应付、凭证和报表入口返回授权记录，越权在写前拒绝。未连接入口继续明确拒绝；不是全 ERP 所有菜单/自定义角色组合穷举。建厂默认关闭，不自动修改已有工厂策略，不碰生产；手机真机及真实用户签署单列。

## 实现边界

生产按计划创建人过滤；来源订单、详情、编辑、开始、结单、中转账及撤销请求校验归属。过滤发生在分页、计数、汇总和导出之前。SELF、SELF_AND_BELOW、DEPT_AND_BELOW 复用现有解析器；ALL及未显式配置覆盖的内部/现场岗契约保持兼容。

财务沿发货、收货、退货、付款核销追溯真实来源订单。未知、损坏、不一致来源不回退操作人；真正无业务来源手工记录按操作人。受限概览、对账及账龄按授权行投影，响应隐藏全厂 balanceAfter。批量审批、驳回和凭证过账在第一笔写入前检查全部 ID。

凭证查询、导出、聚合在 SQL 内过滤来源，不先装载全厂凭证 ID；冲销继承原凭证。三表显示“授权凭证发生额投影”，不伪装完整法定报表。全厂月结、期间/全局财务配置写、信用检查和期初纠错仍要求全厂范围。

## 修复及验证复用

真实页面发现并修复两处断链：生产导出要求页面未传日期，改为可选，按钮明确“导出授权范围”；受限财务原生分页被追加实体驼峰排序，改用 SQL 自带排序。分别有真实请求绑定、三条分页调用回归及修复后的页面/下载证据。

本地相关测试按类去重86类、575项通过，0失败/错误/跳过。这是多次目标运行汇总，不冒称一次全量；仅补失败类和UI修复5项（BUILD SUCCESS）。真实 JPA Context、三条原生 PG 门禁及66000行凭证样本通过。Windows wrapper的2项平台跳过单列，最终native runner仍须执行。冻结后只跑一次必要最终PR CI；实际 Tests run、BUILD、head和手动合并结果以PR及最终回执为准。

首轮native CI的三条新增范围门禁均实跑通过，但暴露两处旧测试夹具问题：根列表仍断言一律403；并发未固定交错，合法串行余额22被误判失败。仅更新两类测试：根列表使用分页且非空的授权记录阳性，保留隐藏/跨厂/写前拒绝断言；供应商读取后加同步屏障强制同版本冲突，保留单胜者及余额断言。两类共62项，失败的两条路由方法精准重跑通过，其余60项证据复用，临时数据库均删除。取消未完成全量以免浪费，测试冻结后重启最终必需CI；产品源码、Web及UI证据不变，Web CI已通过5685项、跳过5项。
