## 最终行为与修复

已批准且有效的报价增加“按报价下单”入口，带入客户、产品、数量下限、单位和含税价；保存报价关联。后端创建、编辑、复制和确认均核对同工厂报价、记录可见范围、审批状态、有效期、客户、产品、单位、起订量及价格，拒绝额外折扣。确认前刷新并锁住报价，防止陈旧审批对象或修订与下单竞态。

批准含税价不能在进入订单后被动态价格策略静默覆盖。净价按实际数据库四位精度与批准含税价反算值严格比较；最终实体在行项目保存前再次校验。

真实 UI 发现 62元/个、2个因先舍入未税行额得到123.99元。最终通过服务端批准含税快照解决：新报价订单为未税109.73、税额14.27、含税124.00。1000个的目标测试为62000.00，不累计净价反算误差。

`V20261103_65__sales_quote_gross_price_snapshot.sql` 只新增可空 `quoted_gross_unit_price NUMERIC(15,2)`，无默认值、无回填。字段标注价格敏感，创建 DTO 不接收它；只有锁定报价能赋值。无快照的历史行完全保留旧公式，未修改旧订单金额。旧的半绑定草稿确认时明确拒绝，可通过完整合法编辑升级并同时重算该单税额。未改V42、Repository查询、销售需求、领料或工厂配置。
