```bash

```

⚠️ **判据不是 `DEPLOY_EXIT=0`**，是三条：制品里 grep 到这次改动的标记 / 进程启动时间
晚于制品 mtime / **真跑一次那条路径**。

⚠️ Java 是 **Blue-Green**：切换后旧端口没有进程是**正常的**（日志里写着
「端口 xxxxx 无残留」）。查活进程要**从监听端口反查 pid**，⛔ 不要 `pgrep -f 关键词`。

⚠️ **grep 部署后的 web 资产是会骗人的仪器**：`assets/` 里 2693 个 js 只加不删，
孤儿 chunk 会让你以为「只改了一半」。判前端改动上没上，只有一条可信路径：
**真用浏览器打开那一屏，看它实际发出的请求。**
